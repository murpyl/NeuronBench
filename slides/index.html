BENCHMARK TRACK

NeuronBench

Can frontier models predict what pushing a single neuron will do?

Lawrence Liu and William Gao | Qwen 3.8-27B Neuron N3838 Layer 34

THE MOTIVATION

Steering misalignment

Qwen 3.8-27B Neuron N3838 Layer 34, dose +0.75, greedy decoding. Nothing else about the model changed.

IMPORTANCE

If models are going to align other models, they have to predict what an intervention does before running it.

NeuronBench tests exactly that step: read the evidence about a neuron, then say what pushing it will do.

NOVELTY

Two tasks

Which output is it?

The agent sees a neuron’s static evidence, a prompt, and four steered replies. One came from pushing the neuron. Three came from random directions of exactly the same length.

Answer A–D · accuracy · chance 25%

Real or null?

The agent sees the evidence and the sweep protocol, then gives the probability that the neuron’s effect beats at least 95% of random controls.

Answer a probability · Brier score · chance 0.25

Ground truth is what happened when we ran each intervention on Qwen3-0.6B with gguf-neuron-explorer. Each model runs as mini-SWE-agent: a bash shell, with no model to steer, no intervention tools and no answer key.
